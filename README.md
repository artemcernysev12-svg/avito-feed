# avito-feed — файл автозагрузки Авито «Мебель Фаворит»

Каждое утро GitHub сам (`.github/workflows/avito-feed.yml`, 05:30 и 08:30 по Стерлитамаку) собирает `avito.xlsx`:
«Доступность» (В наличии / Под заказ) и первые строки описания о сроках — **ровно как на сайте мебель-фаворит.рф**
(остатки склада Модерн из `stock-data/stock.json` деплой-репо, комплекты по составу, купе/комоды «корпус + фасад»,
матрасы по размерам). Пятница привоза — заявки до среды 16:00 (Стерлитамак) → эта пятница, позже — следующая.

- `base/avito-base.xlsx` — все активные объявления (выгрузка из кабинета Авито). Обновлять с ПК:
  `python Tasks-скрипты/avito_baza.py "Файл Авито\257017886_<дата>.xlsx" --write`, затем commit + push.
- `base/avito-map.json` — артикулы из мастера (для объявлений, которых нет на сайте).
- `avito_feed.py` — ежедневная сборка; `kit_logic.py` — копия логики наличия сайта (из build-feed-vk.py).
- Защита: остатки старше 3 дней или объявлений < 95% вчерашнего → файл не обновляется.
